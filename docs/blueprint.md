# **App Name**: PagePulse

## Core Features:

- URL Analysis: Accept a URL input from the user and trigger the analysis process.
- Performance Scoring: Calculate a performance score using Lighthouse metrics.
- Web Vitals Reporting: Display key Web Vitals (LCP, CLS, TBT) in a clear format.
- Unused Code Detection: Tool to detect and quantify unused CSS and JavaScript, helping users optimize their web pages. LLM reasoning decides when and how to incorporate coverage data.
- Detailed Reports: Provide reports detailing page speed metrics and optimizations, offering actionable recommendations. Uses tool to check coverage
- Downloadable Reports: Allow users to download reports in JSON format.
- Clear results display: Present optimization suggestions using the report output data

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a professional and trustworthy feel.
- Background color: Dark gray (#263238) for a modern dark theme.
- Accent color: Cyan (#00BCD4) to highlight key metrics and call-to-action buttons.
- Body and headline font: 'Inter', a sans-serif font, provides a modern, machined look suitable for both headlines and body text.
- Use minimalist icons to represent different metrics and functionalities.
- Dashboard-like layout with cards for key metrics and tables for detailed reports.
- Subtle animations for loading states and transitions to enhance user experience.
